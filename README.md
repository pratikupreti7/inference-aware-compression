# Inference-Aware Error-Bounded Compression for On-Device ML in Wearable Health Systems

Reproducible experiments and paper sources (conference version `paper.tex`, journal version `paper_journal.tex`).
Every number and table in the papers is generated by the scripts below; nothing is typed by hand.

## Layout
| Path | Purpose |
|---|---|
| `wesad_compression_experiments.py` | Codec (closed-loop Lorenzo + quantization + Huffman), baselines (scalar quantization, ZFP, downsampling, lossless), bound verification, 47 window features, FFNN LOSO on WESAD, paired stats. Writes `results/`. |
| `bound_allocation_experiments.py` | Inference-aware bound allocation (feature-distortion and classifier-aware proxies, nested in LOSO folds, exhaustive enumeration), matched-ratio analysis, Pareto figures. `--dataset wesad|dalia`. Writes `results_alloc/`, `results_alloc_dalia/`. |
| `dalia_experiments.py` | Same codec/features/FFNN protocol on PPG-DaLiA eight-class activity recognition. Writes `results_dalia/`. |
| `nurse_experiments.py` | Same protocol on the in-the-wild nurse stress dataset (binary self-reported stress, macro-F1 primary). Writes `results_nurse/`. |
| `cnn_experiments.py` | 1-D CNN on raw reconstructed waveforms (WESAD). Writes `results_cnn/`. |
| `cnn_allocation_experiments.py` | FFNN-chosen allocations evaluated with the CNN (cross-model transfer test). Writes `results_cnn_alloc/`. |
| `firmware/` | Single-precision C encoder (`codec.c`), native equivalence test vs. the reference codec, and Cortex-M4 emulation (Unicorn) with instruction counts. Writes `results_fw/`. |
| `paper.tex` / `paper_journal.tex` | Papers; `\input` all numbers from `results*/macros*.tex` and tables from `results*/table_*.tex`. |
| `paper_jsen.tex` | Journal paper in the official IEEE Sensors Journal template (`ieeecolor.cls` + `jsen.sty`); same body, submission formatting. |
| `data/WESAD/S*/S*.pkl` | WESAD pickles (download from Uni Siegen; not in git). |
| `data/DALIA/S*.npz` | PPG-DaLiA wrist channels + activity labels, slimmed from the UCI pickles (see below). |
| `data/NURSE/` | Nurse stress dataset, prepared with `tools/nurse_prepare.py` from the Dryad download (not in git). |

## Run (macOS/Linux)
```
uv venv --python 3.11 .venv
uv pip install --python .venv/bin/python numpy scipy scikit-learn numba zfpy matplotlib torch
# WESAD: place S*/S*.pkl under data/WESAD
.venv/bin/python wesad_compression_experiments.py --wesad_dir data/WESAD --out results          # ~10 min
.venv/bin/python bound_allocation_experiments.py --wesad_dir data/WESAD --out results_alloc     # ~15 min
# PPG-DaLiA: unzip PPG_FieldStudy/S*/S*.pkl, then keep wrist channels only with `python tools/slim_dalia.py data.zip data/DALIA`
.venv/bin/python dalia_experiments.py --dalia_dir data/DALIA --out results_dalia                 # ~70 min
.venv/bin/python bound_allocation_experiments.py --wesad_dir data/DALIA --dataset dalia --out results_alloc_dalia --main_results results_dalia/results.json
# Nurse: download from Dryad (doi:10.5061/dryad.5hqbzkh6f), then `python tools/nurse_prepare.py <download> data/NURSE`
.venv/bin/python nurse_experiments.py --nurse_dir data/NURSE --out results_nurse
.venv/bin/python bound_allocation_experiments.py --wesad_dir data/NURSE --dataset nurse --out results_alloc_nurse --main_results results_nurse/results.json
.venv/bin/python cnn_experiments.py --wesad_dir data/WESAD --out results_cnn                    # ~2 h (Apple GPU)
.venv/bin/python cnn_allocation_experiments.py --wesad_dir data/WESAD --out results_cnn_alloc
tectonic paper_journal.tex   # https://tectonic-typesetting.github.io
```
Every script has `--quick` (smoke test) and a `--rewrite_tex` / `--rewrite` flag that regenerates LaTeX outputs from the saved `results*.json` without re-running.
`results/verification.txt` must show `OK` for every error-bounded configuration; the scripts abort before writing LaTeX if any bound is violated.
